# Errors and how to fix them

Every error is `{ "error": "<code>", "message": "..." }`. The ones to handle: `rate_limited` (429, wait 60 s), `backtest_busy` (429, retry after 60 s), `backtest_limit` (429, 5 backtests per 24 hours on the trial, 20 with a paid plan), `hyperliquid_refused` with `reason: "no_deposit"` (deposit first) or `"too_many_agents"` (revoke an API wallet on Hyperliquid), `alert_channel_required` (link a webhook), `key_required` (409, confirm the trading key before `/account/unified`), `switch_failed` (502, switch in Hyperliquid's settings), `activation_required` (trial not started), `insufficient_usdc` (409, deposit USDC), `wrong_amount` / `wrong_token` / `invalid_payment_action` / `stale_signature` (prepare and sign again). Sign-in and access: `invalid_nonce` (401, a signature signs in once: ask for a new nonce), `session_required` (401, send `Authorization: Bearer <token>`, on the MCP server too), `token_in_arguments` (MCP: put the token in the header, never in a tool argument), `agent_code_expired` (401, the code from the owner's Profile ended: ask them for a new one), `view_only` (403, the owner's code only reads: ask for a Manage copying code), `wallet_required` (403, an owner's code can't link or unlink Telegram or a webhook: the owner does it on waketrades.com), `geo_blocked` (451, restricted location of the request's IP address). Full list: `https://waketrades.com/docs/api/endpoints`.

Reading `GET /me` → `copiesOnHold.reasons` tells you why new copies would not open: `not_activated` (finish sign-up), `paused` (`POST /resume`), `trial_expired` / `plan_expired` (pay), `key_invalid` (sign a new trading key), `platform_paused` (wait), `no_leaders` (`PUT /settings`), `no_margin` (deposit USDC), `not_unified` (`POST /account/unified {}`), `manual_positions` (close the positions listed in `coins`), `xyz_not_unified` (advanced only: xyz markets wait).
